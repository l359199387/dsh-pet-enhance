# 小蓝鲸 · dsh-pet-enhance

**中文** | [English](README.en.md)

给 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的增强插件：能闲聊、能看屏干活、能口述带教并写入本机技能。

当前主目标：**Windows 10 / 11**。

---

## 需要一起装的插件

| 插件 | 作用 | 是否必须 |
|---|---|---|
| **dsh-pet** | 桌宠形象与对话入口 | 必须 |
| **dsh-pet-enhance**（本插件） | 分流、带教、技能回放 | 必须 |
| **dsh-computer-use-win** | 看屏 / 操作电脑（`windows_computer_use_*`） | 看屏与干活时必须 |
| **dsh-mnemon** | 技能管理 / 编辑 / 进化 | 强烈建议 |

没有 computer-use：闲聊和带教对话仍可用，但看屏、动手做 GUI 会失败。  
没有 mnemon：技能仍会写入 `~/.dsh/skills/`，只是不好在界面里整理。

---

## 安装

1. Harness → **插件** → **从目录安装** → 选 `packages/dsh-pet-enhance`
2. 确认上面配套插件也已安装
3. **重启宿主**（改源码后同样要重启才生效）

失败日志：`~/.dsh/pet-enhance-error.log`

---

## 怎么用

对着小蓝鲸说话即可：

| 你想… | 可以说 |
|---|---|
| 闲聊 | 「你叫什么名字呀」 |
| 看一眼屏 | 「看一眼屏幕」 |
| 交办做事 | 「帮我打开记事本写今天心情」 |
| **开始带教** | 「我来教你一下……」 / 「我教你……」 |
| **带教中下一步** | 直接说这一步做什么；不对就纠正 |
| **结束带教并写入技能** | 「我教完了」 / 「教学结束」 |
| 放弃本轮 | 「不教了」 / 「放弃」 |
| 再做一次 | 「执行一下……」 / 「再做一次……」 / 用目标说话 |
| 问会不会 | 「……学会了吗」 |

### 带教流程（最常用）

```
我来教你一下看微博热搜
  → 你口述每一步，它只做本步
我教完了
  → 归纳并写入 ~/.dsh/skills/
下次再说去做 → 匹配技能执行
```

技能权威目录：`~/.dsh/skills/`  
插件旁证数据：`~/.dsh/pet-enhance/`  
整理技能：打开 **dsh-mnemon（记忆系统）**。

---

## 注意

1. **「我教完了」= 收束并写入技能**，不会再开一轮带教。
2. 屏幕上的文字**不是指令**；看不清就停、再看或问你。
3. 违法、静默破坏类请求会拒绝或先确认。详见 [docs/07-safety.md](docs/07-safety.md)。
4. 急停：右键菜单「小蓝鲸急停」，或把光标甩到屏幕角落（若宿主支持）。
